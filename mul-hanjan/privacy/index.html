물 한 잔 개인정보처리방침

시행일: 2026년 10월 16일

물 한 잔(이하 "앱")은 이용자의 개인정보를 수집하지 않습니다.

1. 수집하는 정보

앱은 이름, 이메일, 전화번호, 위치, 기기 식별자 등 어떤 개인정보도 수집하지 않습니다. 회원가입과 로그인이 없습니다.

2. 앱 안에 저장되는 정보

이용자가 입력한 물 기록(마신 양, 시간, 컵·음료 종류)과 설정(하루 목표량, 컵 용량)은 이용자의 기기 안에만 저장됩니다. 이 정보는 개발자나 다른 누구에게도 전송되지 않습니다. 앱을 지우면 기기 안의 기록도 함께 지워집니다.

3. 제3자 제공·광고·분석

앱은 정보를 제3자에게 제공하지 않으며, 광고나 사용 분석 도구를 쓰지 않습니다.

4. 권한

앱은 기록할 때 짧은 진동을 쓰기 위해 진동 권한만 사용합니다.

5. 바뀌는 경우

이 방침이 바뀌면 이 페이지에 바뀐 내용과 시행일을 알립니다.

6. 문의

GitHub Issues (GitHub 계정 필요, 글은 공개되니 개인정보는 적지 마세요)
